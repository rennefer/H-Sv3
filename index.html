Budge — An Egyptian Hieroglyphic Dictionary (raw extraction)

Provisional OCR + column-segmentation of both volumes (1067 pages, 29,188 entries; crops re-cut and hand-checked page by page). Each result shows its own source-page crop so you can check the OCR against the real text. Headwords/transliterations/definitions have not been individually parsed or checked against the printed book yet — this is a browsing/search tool over the raw pipeline output, not a finished dictionary. Images are packed into ~30 sprite sheets (sheets/) rather than 37,000 loose files, purely so the dataset is easy to host and upload.
